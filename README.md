# Vikas Dhruw — Blog

> Minimal, terminal-driven personal blog.

## About
A personal space where I write about things I build, break, learn, and occasionally fix. Built with a FastAPI backend serving raw Markdown content and a React frontend styled after a retro Linux terminal.

## Stack
* **Backend:** Python / FastAPI / PyYAML
* **Frontend:** React / Vite / Tailwind CSS / React Markdown
* **Theme:** Custom VT323 monospace terminal aesthetic
