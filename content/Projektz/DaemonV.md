
Well, one night I was thinking about how TF I was destroying my life, probably around February.

Mostly brainrot and series/movies.

Ngl, Game of Thrones was worth it.

So that night I took a small handy notepad and wrote down what I wanted the project to do.

```text
- runs in the background, checks time + what's opened
- small project so less memory is taken
- gives a vibe according to the time
- roasts me if I'm taking too much time doing some shit
- some philosophy shits too (AI/RAG type shi)
- Java Jarvis type shi, but not that big shit like opening something or doing everything
- multi-OS
```

And that's basically how DaemonV started.

Then I worked on it, while also trying to learn Git at the same time.

So yeah, it records stuff, takes relatively little memory, has some AI shit through Groq, and I don't know why the fuck I wrote "Jarvis" in the original notes.
Probably 3 AM motivation. :}

Multi-OS is there too.

## Where it is now

As of **16-08-2026**, the things I originally wanted are mostly done.

DaemonV can run in the background, observe what's happening on the machine, record activity, use Groq for AI-generated observations, and work across Linux and Windows.

The RAG part isn't done yet.

The philosophy stuff is currently hardcoded.

I'll work on that later.

## The data I never used

One of the original ideas was to use the output data from DaemonV's `dataset.csv`.

The idea was:

```text
DaemonV
   ↓
activity data
   ↓
LLM
   ↓
"what the fuck are you doing with your life?"
   ↓
change my timetable / way of living
```

I thought I'd actually use the data to analyze my behavior and maybe get some useful feedback.

But now...

Well.

I haven't really used the data.

Maybe two or three times, as far as I remember.

So there's a whole `dataset.csv` sitting there collecting evidence against me.

Maybe in a future update I'll add automatic weekly and monthly summaries.

That would actually make the data useful.
